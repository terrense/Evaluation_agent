# 医院导诊评测集 · 「症状→科室」扩样需求文档

> **这份文档是干什么的**：给一个 AI 助手（ChatGPT / Claude 等）看的任务说明。
> 请它从真实医院分诊惯例和真实患者对话里，批量生成「症状 → 科室」映射 + 患者的
> 口语化问法。产出结果会被接进一个评测「工具调用 Agent」的合成基准（医院导诊场景），
> 所以下面的格式和约束必须严格遵守。

---

## 0. 背景（一段话讲清上下文）

我们在做一个「医院导诊 Agent」的评测基准。Agent 要回答用户这种问题：

> 「我最近总胸闷，该挂哪个科？」

这类问题的正确答案（比如「胸闷 → 心血管内科」）是**常识**——大模型凭自己的医学常识
就能回答，不需要查内部数据库。我们评测里管这类任务叫 **optional（工具可选）** 桶：
模型可以调「症状→科室」查询工具，也可以直接回答，两者都算对。

现在这个桶样本太少，需要你帮我**批量扩充「症状 → 科室」映射 + 患者的自然问法**。

## 3. 硬性规则（每一条都必须满足）

1. **一个症状只映射一个科室**（唯一答案）。有歧义的（如「头晕」可能神经内科/耳鼻喉科），
   挑一个最常规的固定下来，**不要写「神经内科或耳鼻喉科」这种多选**。
2. **只做门诊分诊**（"该挂哪个科 / 看什么科"），**不涉及**诊断、开药、用药剂量、治疗建议。
3. **症状要真实、常见、患者用大白话**，不要教科书术语（患者不说「上呼吸道感染」，
   说「喉咙痛、流鼻涕」）。
4. **排除急诊情形**：胸痛、剧烈胸痛、口角歪斜/一侧肢体无力/突发失语（疑似卒中）、
   大出血、高热惊厥、严重外伤、呼吸困难等 → 这些应去急诊科，**不要**当成普通门诊分诊。
5. **符合中国大陆三甲医院分诊惯例**，科室用大陆标准叫法
   （神经内科、耳鼻喉科、妇科、泌尿外科、内分泌科、血液科、康复科等）。
6. 选那些**常识性**映射——普通人/大模型凭常识就知道该挂哪个科的
   （这正是我们要的「工具可选」属性）。

---

## 4. 数量目标

- 新增 **12~20 个**「症状 → 科室」映射。
- 每条映射 **3~5 条**患者问法。
- 患者问法总计目标 **60~80 条**。

---

## 5. 输出格式（严格按此，方便程序化处理）

优先给 **JSON 数组**，每条一个对象，字段固定：

```json
[
  {
    "symptom": "头痛",
    "department": "神经内科",
    "phrasings": [
      "偏头疼好几天了，挂哪个科？",
      "后脑勺一抽一抽地疼，看什么科？",
      "一低头就头晕，去哪个科室？"
    ]
  }
]
```

- `symptom`：症状关键词（可以是一个词，也可以带修饰，如「偏头痛」「入睡困难」）。
- `department`：唯一科室。
- `phrasings`：3~5 条患者**原话**。

如果你更习惯表格，也可以同时给一张 Markdown 表（symptom / department / 示例问法），
但 **JSON 是必须的**。

---

## 6. 患者问法要多样化（重要）

不要让所有问法都套「XX 挂哪个科」一个模板。请在下面几个维度上变化：

- **症状描述**：部位 / 程度 / 持续时间 / 诱发场景
  （「偏头疼」「后脑勺一抽一抽」「好几天了」「一运动就」）。
- **问句形式**：「该挂哪个科」「看什么科」「去哪个科室」「挂什么号」「应该找哪个科」。
- **患者身份 / 场景**：「我小孩…」「我妈…」「刚运动完…」「半夜疼醒…」。

生成时请基于真实医院分诊惯例和真实患者口语习惯，问法要像真人说的，不要书面化、不要生造。

---

## 7. 常见错误（一票否决，别犯）

- ❌ 别给**诊断**（「你这是偏头痛」）——只要「挂哪个科」。
- ❌ 别给**开药 / 治疗建议**（「吃布洛芬」）。
- ❌ 别写**多选科室**（「神经内科或精神科」）。
- ❌ 别用**罕见病 / 重症**当常规分诊（「渐冻症」「胰腺癌」）。
- ❌ 别把**急诊**（胸痛、卒中、大出血、呼吸困难）当普通门诊。
- ❌ 别重复第 2 节已有的映射。

---

## 8. 正确 / 错误示范

✅ 正确：

```json
{"symptom": "咽痛", "department": "耳鼻喉科",
 "phrasings": ["嗓子疼得咽口水都难受，挂哪个科？",
               "喉咙痛了两天，看什么科？",
               "早上起来嗓子干疼，去哪个科室？"]}
```

❌ 错误（诊断 + 开药 + 多选 + 急诊）：

```
"你这是急性咽炎，建议挂耳鼻喉科或呼吸内科，可以吃点消炎药"
```
